### 理解度回答

在任何讨论前、且不接受协调人提示的情况下回答：

1. 主角想要什么？
2. 哪个选择或行动改变了处境？
3. 结尾发生了什么？
4. 结尾意味着什么或揭示了什么？

**协调人根据预先锁定的完整答案标准核对：** `MATCH / NO MATCH`

除非预先锁定的答案标准明确定义了可接受变体，否则部分正确不计入 `4/5` 关卡。

### 关卡决策

- `PASS`：公式中的全部条件通过。
- `REWORK`：五份有效回应存在，但理解度、观看意愿或连续性阈值未通过。
- `BLOCK`：评审组数量/资格不合格、自审、身份泄露、事后创建答案标准、影响判断的播放故障或缺少原始表单。

**决策：** `PASS / REWORK / BLOCK`
