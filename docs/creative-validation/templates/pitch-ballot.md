# Film 01 提案盲评表

## 使用边界

本表用于 `P01-P09` 九个匿名提案的独立评审。评审对象是提案本身，不是作者、模型、生成工具或任何未提供的背景信息。

- 合格评审共 5 人；每人独立填写一份完整盲评表。
- 五名评审必须在同一版本的九案上评分，且每个提案每个维度均须填写 `1-5` 的整数分。
- 五份有效盲评表全部锁定前，不得计算汇总、排序、宣布候选或选择胜者。
- 本表不授权进入节拍表、剧本、DirectorKit 或任何付费生成流程。

## 评分规则

只根据提案中明确呈现的内容评分，不因个人偏好、作者身份、模型名称或“我可以替它补好”而加分。

| 分数 | 含义 |
| ---: | --- |
| `1` | 明显不足，无法满足本维度要求 |
| `2` | 有局部可用点，但存在严重问题 |
| `3` | 基本成立，但仍有明显风险或普通化表达 |
| `4` | 清楚、有效，达到本片单要求 |
| `5` | 极强且具体，几乎没有该维度的可见短板 |

严重可行性风险是：在单人、单地点、30 秒、9:16、少对白和当前镜词能力边界内，可能导致核心机关无法拍出、无法理解或需要未批准资源的风险。每项风险必须写明证据，不得用笼统的“有点难”代替。

### 维度定义

- **钩子**：前 3 秒是否有清楚、可见且值得继续看的异常或问题。
- **清晰度**：不依赖作者解释，观众是否能理解角色在做什么以及情境如何变化。
- **因果**：角色动作、阻碍、升级和结果是否形成必要且可追踪的因果链。
- **原创性**：核心机关和表达是否避免熟悉广告、影视桥段、网络段子或简单替换。
- **视觉可行性**：是否能在已批准的单人单地约束、30 秒时长和当前生成能力内稳定表达。
- **回收潜力**：结尾是否有机会重新解释前文，并让关键细节获得新意义，而不是靠字幕补答案。

### 平分规则

若多个提案的六维总均分相同，按以下顺序处理，不得由 Showrunner 个人偏好决定：

1. 比较各自六个维度中的最低分；最低分更高者优先。
2. 若仍相同，比较严重可行性风险数量；风险更少者优先。
3. 若仍无法分出结果，将并列提案重新生成匿名、同版本的盲评票，只发送给原五名合格评审；新一轮仍须在禁止讨论的前提下独立完成。
4. 新一轮完成前保持并列，不得宣布胜者、推进节拍表或进入镜词。
