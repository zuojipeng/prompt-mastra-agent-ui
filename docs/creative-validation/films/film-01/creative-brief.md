# Film 01 创作简报 · 30 秒日常视觉反转片

状态：提案征集中，尚未选题
片单编号：`film-01`
负责人：Showrunner Agent
当前关卡：九案齐备后进入匿名盲选

## 创作任务

创作一支发生在当代中国日常生活中的 30 秒竖屏短片。影片只出现一名角色，只使用一个地点，以动作、物件、空间关系和画面信息完成叙事，在结尾产生能够回看前文的视觉反转。

反转不能只是“原来是一场梦”“原来在拍视频”或依赖字幕公布答案。观众应能在第一次观看时理解结尾，并在回想前段细节时发现反转已经被公平铺垫。

## 目标观众

- 16 至 45 岁、习惯观看中文竖屏短视频的普通观众。
- 不要求了解 AI 视频、电影术语或特定网络梗。
- 在无声音或低音量环境下仍能理解主要故事。

## 硬性约束

- 时长：目标 `30s`，允许成片在 `27-33s` 内调整。
- 画幅：移动端 `9:16`。
- 角色：画面中只能出现 1 名可识别人物；照片、屏幕或镜面中不得出现第二名可识别人物。
- 地点：1 个连续空间，不通过门、窗、监控或手机画面切换到第二地点。
- 对白：优先无对白；如必须使用，最多一句且不承担解释反转的功能。
- 叙事：必须包含钩子、建立、升级和回收。
- 语境：当代中国生活中可识别的空间、物件或行为，但不依赖地域刻板印象。
- 原创：不得改写著名广告、短片、影视桥段或流行段子的核心机关。
- 制作：避免多人交互、动物表演、复杂手部特写、可读小字、快速换装和大规模物理破坏。

## 创作偏好

- 从一个熟悉动作开始，用异常细节制造“为什么”。
- 反转同时改变角色动机或物件意义，而不是只改变地点名称。
- 允许喜剧、温情、悬疑、轻奇幻或环保表达，但不能变成公益口号。
- 优先使用能在首帧识别、能贯穿全片、能在结尾完成回收的核心道具。
- 镜头数量建议 `4-6` 个；每个镜头必须推动信息或情绪。

## 禁止解法

- 梦境、昏迷、死亡后才发现、精神疾病误导。
- 用最后一张说明卡、旁白或手机长文本解释真相。
- “主角其实是机器人/鬼/外星人”但前文没有可见证据。
- 以偷拍、羞辱、疾病、贫困或残障作为廉价笑点。
- 品牌露出、真实商标、受保护角色或未经授权的音乐依赖。
- 仅有形式花活，没有角色目标、阻碍或结果变化。

## 提案提交格式

每个匿名提案必须提供：

1. 标题和类型气质。
2. 钩子。
3. 建立 / 升级 / 回收。
4. 视觉可行性说明。
5. 原创性风险及规避方式。
6. 一句可直接用于当前镜词 A 组的原始创意。

提案不得包含作者、模型、会话或生成工具信息。编号统一使用 `P01-P09`。

## 匿名评审维度

| 维度 | 评审问题 |
| --- | --- |
| 钩子 | 前 3 秒是否出现清楚、可见且值得继续看的异常？ |
| 清晰度 | 不听解释是否能复述角色在做什么？ |
| 因果 | 升级和回收是否由前面动作自然导致？ |
| 角色 | 反转是否改变我们对角色目标或选择的理解？ |
| 原创性 | 核心机关是否避免熟悉广告、段子和影视套路？ |
| 结尾回收 | 最后一个画面是否让前文细节获得新意义？ |
| 可拍性 | 在单人、单地、30 秒和当前生成能力下是否可控？ |

每项采用 `1-5` 分。创意盲选阶段只形成候选排序，不直接锁定剧本；排名靠前的方案仍须通过相似性检查和 AI 制片可行性复核。

## 验证产物

胜选后，同一核心故事必须形成 A/B/C 三组材料：

- A 组使用提案中的“一句话原始创意”。
- B 组使用后续批准的锁定剧本进入镜词。
- C 组由导演 Agent 根据锁定剧本人工拆解镜头。

当前阶段只完成创作简报和九个匿名提案，不选胜者、不写节拍表、不生成 DirectorKit。

## 执行交接

Showrunner 将本简报作为唯一创作边界，分别向三个隔离的编剧 Agent 发放，不向任何编剧暴露其他提案。常规提案生产可以使用 `5.6luna` 子 Agent，但每份提案必须经过独立的故事编辑、原创性风险检查和制片可行性复核；模型路由不构成作者身份，也不写入匿名评审材料。

在九案齐备前，任何 Agent 都不得建议胜者、合并提案、补写节拍表或把某个提案送入镜词。评审只接收去除作者、模型和会话信息后的 `P01-P09` 文件。
