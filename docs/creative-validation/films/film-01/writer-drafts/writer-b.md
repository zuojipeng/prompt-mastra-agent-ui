## P01《留一格》

- **气质**：克制、微暖的日常观察。
- **钩子**：快递柜前，主角把自己的包裹取出后，立刻用肩膀顶住正在自动关闭的柜门；他明明已经拿到东西，却不让门合上。
- **建立**：他把包裹放在脚边，反复按开门键，观察柜内上下两格的缝隙；每次门快合上，他都把手里的纸袋折得更薄，试图塞进那条缝。
- **升级**：纸袋被门夹皱，包裹差点滚进旁边的柜底；主角只好蹲下，一手护住包裹，一手继续撑门，自动提示灯开始闪烁，他的取件时间明显被拖长。
- **回收**：他终于把纸袋抽出，放弃塞入柜门，转身离开。门合上的最后一刻，镜头看见纸袋并非空的：里面是一只被压扁的透明文件夹，而柜内那格的底部正卡着一张同样大小的遗失证件套。前面的“留一格”其实是在避免门把它夹坏；他放弃取走它，却把它留在原处让失主容易看到。
- **主角欲望 / 选择 / 代价**：想尽快取走自己的包裹；选择占用自己的取件时间和弄坏纸袋，保护一个不属于自己的物件；代价是错过电梯或额外等待，并损失一个可用的文件夹。
- **视觉可行性**：单一快递柜前景别，1 名主角，4-5 个镜头；不用可读小字，靠门缝、自动关门、纸袋变形和证件套轮廓完成因果；竖屏能清楚保留手、包裹和柜门的空间关系。
- **原创性风险**：可能被联想到“替陌生人保管遗失物”的常见暖心短片；规避方式是把核心机关放在“自动柜门与遗失物尺寸的关系”上，主角最终不拿走、不等待失主，也不靠字幕解释。
- **一句原始创意**：一个急着取件的人反复撑住快递柜门，最后才看出他牺牲自己的文件夹，是为了让柜内一件陌生人的遗失物不被门夹坏。

## P02《静音键》

- **气质**：安静、略带幽默的城市体贴。
- **钩子**：共享办公区的打印机突然连续吐纸，主角冲过去，却没有撕下纸张，而是先按住“静音”触控键，再用身体挡住出纸口。
- **建立**：他把打印机旁的纸盒推回原位，捡起散落的纸张；每吐出一页，他都迅速接住，翻面朝下，不看内容，只盯着机器上跳动的页数图标。
- **升级**：机器卡纸，主角不得不打开侧盖，手臂伸进狭窄的出纸口；纸张被滚轮卷出，带着他手里的袖口一起往里扯。他先松开袖口，改用一支笔轻轻拨纸，声音仍然被他按在静音状态里。
- **回收**：卡纸排除，最后一张纸滑出。主角把所有纸整齐叠好，关掉打印机提示音，转身离开；镜头留在机器上，屏幕显示的不是打印页数，而是一排“测试音量”的小喇叭图标，刚才吐出的每一页其实都是打印机自检时误出的空白校准纸。主角保护的不是文件，而是整间安静的办公区。
- **主角欲望 / 选择 / 代价**：想在安静环境里完成自己的工作；选择牺牲袖口、时间和一支笔，先处理会打扰所有人的机器；代价是自己的工作被打断，袖口留下墨粉和褶痕。
- **视觉可行性**：单一打印机角落，1 名主角，5 个镜头；纸张不出现可读内容，使用出纸、卡纸、袖口和静音图标等大形状信息；可用无对白、低音量环境声完成叙事。
- **原创性风险**：打印机故障和“替大家解决麻烦”较常见；规避方式是让反转改变纸张意义，主角从保护文件转为保护公共安静，并用前段持续按住静音键公平铺垫。
- **一句原始创意**：一个人冒着袖口被打印机卷住的代价去压低噪音，最后发现自己一直处理的是机器的空白自检纸，而不是谁的文件。

## P03《反着放》

- **气质**：克制、带一点轻悬疑的生活细节。
- **钩子**：自助寄存柜前，主角把一把折叠伞放进柜子，马上又取出，伞尖朝里、伞柄朝外地重新放入；他连续改了三次方向。
- **建立**：他拿自己的钥匙卡反复试开同一个柜门，把伞收得很紧，却故意让伞带露出柜门边；他退后检查柜门是否能合上，再把柜门打开。
- **升级**：寄存柜提示即将锁定，主角必须在倒计时前离开；他最终把伞整个推进去，关门后又用掌根抵住门，任由倒计时归零，导致钥匙卡被系统弹回。他蹲在地上捡卡，明显已经迟到。
- **回收**：柜门终于锁上，主角拿着卡离开。镜头从柜门低处看见：柜内的伞柄并非他的握把，而是一枚卡在底部的旧门把手，伞带一直在把它托离锁舌；主角调方向是在让柜门完整扣住，避免这个松脱的金属件掉出来绊到下一位使用者。最后他把自己的钥匙卡重新收好，手指上多了一道金属划痕。
- **主角欲望 / 选择 / 代价**：想赶上即将开始的工作或约定；选择多次开关柜门并延误自己，确保柜内松脱的金属件不会造成后续风险；代价是迟到、划伤手指，也放弃了对自己物品的快速确认。
- **视觉可行性**：单一寄存柜区域，1 名主角，4-6 个镜头；不需要读文字，只呈现钥匙卡、柜门倒计时灯、折叠伞方向和金属件的形状关系；近景可控，竖屏适合把“门缝里卡住的东西”作为结尾视觉焦点。
- **原创性风险**：可能接近“路人避免公共设施危险”的公益叙事；规避方式是把动机藏在主角持续调整伞的具体动作中，不出现口号、受害者或夸张事故，结尾只回收锁舌与伞带的机械关系。
- **一句原始创意**：一个急着离开的人反复调整寄存柜里的折叠伞，最后才看出他付出迟到和划伤的代价，是为了让一枚松脱的金属件被柜门稳稳托住。
