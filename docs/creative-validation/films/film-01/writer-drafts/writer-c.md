# P07

## 工作标题：杯底的水平线

- **类型气质：** 视觉悬疑，收束于克制的温情。
- **钩子：** 首秒，一个装着水的透明杯停在明显倾斜的厨房台面上，水面却始终水平；唯一的主角立刻伸手去扶杯子。
- **建立：** 当代中国小户型厨房。主角想在杯里调好一小团修补陶瓷用的粉浆，先用硬币、折纸和抹布垫台脚，杯子每次都在同一个位置恢复“异常”的水平线。
- **升级：** 主角把杯子移到灶台、砧板和地砖上测试，发现水面变化正常；回到台面后，他撬起杯底，手指被一层看不见的黏性薄垫粘住，杯子才突然歪倒，粉浆洒出一半。
- **回收 / 结局：** 他翻过杯子，露出杯底粘着的透明防滑垫；再看台面，所谓倾斜其实是台面边缘的视觉错觉。主角没有重来，而是用剩下的粉浆把一只裂开的旧碗补好，代价是放弃本来足量的修补材料。
- **主角欲望 / 选择 / 成本：** 欲望是修好一只舍不得丢的旧碗；选择是先追查异常杯子还是直接使用材料；成本是追查过程中洒掉一半粉浆，只能完成不完美的修补。
- **视觉可行性：** 单一厨房，单人，4-5个固定或半固定镜头；透明防滑垫、杯中水面、硬币和裂碗均为易控实物，不需要对白、文字或屏幕。用真实台面透视与轻微移位完成公平铺垫。
- **原创性风险：** “水面保持水平”可能接近常见视觉错觉视频；规避方式是把机关落在杯底防滑垫和主角修碗的具体选择上，让结尾改变主角动机，而非只展示错觉。
- **一句原始创意：** 他追查一只在斜台面上保持水平的水杯，最后发现真正需要被扶平的不是台面，而是一只快要碎掉的旧碗。

# P08

## 工作标题：门缝里的米

- **类型气质：** 日常视觉谜案，带一点诗意的误导。
- **钩子：** 玄关地面有一串米粒，竟从已经合上的鞋柜门缝里一粒粒“退”出来；主角蹲下按住最后一粒，门缝又冒出新的米粒。
- **建立：** 当代中国住宅玄关。主角急着把一只纸箱推进鞋柜旁的空位，米粒挡住滚轮；他用卡片、胶带和扫帚柄反复清理门缝，却始终清不干净。
- **升级：** 他拔出鞋柜抽屉，把纸箱抬起，米粒的路径突然从门缝转向箱底；箱底看起来完好，主角便把箱子竖起来轻拍，更多米粒落下，纸箱的一角也被压裂。
- **回收 / 结局：** 主角撕开箱底，里面没有米，只有一只倒扣的竹筛；竹筛的细孔把藏在箱底夹层里的米缓慢漏出。原来他一直在搬运一箱要送人的米，最后必须在破损纸箱和完整竹筛之间做选择：他拆箱，用竹筛把米重新收拢，牺牲纸箱外观但保住了米。
- **主角欲望 / 选择 / 成本：** 欲望是把一箱米完整搬到玄关空位；选择是继续遮掩漏米还是拆开查明；成本是撕坏纸箱并暴露里面的物件，只能用竹筛重新整理。
- **视觉可行性：** 一个玄关连续空间，单人，米粒、纸箱、竹筛和鞋柜构成完整视觉链；用俯拍米粒轨迹和一个箱底翻转完成回收，避免可读标签、复杂手部特写和第二地点。
- **原创性风险：** “箱中漏出意外物件”是常见小机关；规避方式是让米粒先制造“门缝在吐米”的空间误判，再以竹筛孔洞和箱底夹层提供前段可见证据，并把结尾落在保住米而非猎奇发现。
- **一句原始创意：** 他以为鞋柜门缝在吐出米粒，直到拆开纸箱才发现，米真正走过的是箱底一张倒扣竹筛的细孔。

# P09

## 工作标题：会回来的折痕

- **类型气质：** 轻悬疑、安静的物件诗。
- **钩子：** 主角把一张白纸折成窄条塞进抽屉，关上抽屉；下一秒，纸条却从桌面另一端露出一条整齐折痕，像自己爬了回来。
- **建立：** 当代中国出租屋书桌。主角想把一只摇晃的木盒垫稳，连续折纸、塞入、关抽屉；每次抽屉拉开，纸条都不在原位，而桌面上多一道方向相同的折痕。
- **升级：** 主角用杯子、书和胶带压住纸条，拉抽屉时仍听到轻响；他把抽屉整个抽出，发现纸条实际卡在抽屉底部，木盒也因反复挪动掉下一颗小木塞，摇晃更加明显。
- **回收 / 结局：** 主角把纸条展开，发现折痕不是纸条移动留下的，而是抽屉底板上的旧裂口压出来的形状；他放弃继续垫纸，取下木盒底部那颗松脱的小木塞，把它装回桌脚的缺口，木盒终于稳定。前面每次“回来的折痕”其实都是抽屉底板在重复压纸。
- **主角欲望 / 选择 / 成本：** 欲望是让木盒稳定，好把一枚易碎的陶制小物放进去；选择是相信纸条的异常还是检查家具结构；成本是弄皱并撕裂唯一一张合适的纸，最后只能把纸条留作盒内缓冲垫。
- **视觉可行性：** 单一书桌区域，单人，抽屉、白纸、木盒和松脱木塞均可连续拍摄；折痕方向、抽屉底板裂口和木塞位置都能在前段露出局部线索，最终无需解释性对白。
- **原创性风险：** “物品仿佛自行移动”容易落入灵异或隐藏角色套路；规避方式是全程只让纸条移动到镜头可见的结构边缘，并在结尾用机械压痕和松脱木塞完成现实主义回收，不引入灵异、梦境或第二人物。
- **一句原始创意：** 一张被塞进抽屉的纸条总带着新折痕回来，直到他发现，真正重复移动的不是纸，而是抽屉底板压出的同一道裂口。
