# 角色与授权

## 权限总表

| 角色 | 主要职责 | 可以决定 | 不可以决定 |
| --- | --- | --- | --- |
| Showrunner / 执行制片 | 统筹片单、目标、预算和阶段放行 | 选题、资源分配、进入下一门禁、暂停项目 | 代替独立评审、绕过版权或发布审批 |
| 故事研究 Agent | 观察、资料、受众和题材研究 | 提交研究包与事实来源 | 直接锁定剧本、编造事实来源 |
| 编剧 Agent A/B/C | 独立提出创意和剧本 | 提交自己的提案和修订稿 | 查看其他编剧初稿、决定最终入选 |
| 故事编辑 Agent | 结构、人物、因果、伏笔和回收审查 | 提出返工意见、阻止结构不合格稿 | 擅自改写并以编辑身份锁稿 |
| 导演 Agent | 视觉叙事、调度、表演和节奏 | 锁稿后提交导演阐述与镜头意图 | 改变锁定剧情而不触发返工 |
| 摄影/美术 Agent | 视觉系统、造型、空间和连续性 | 提交视觉圣经与连续性表 | 牺牲故事清晰度追求风格 |
| AI 制片监督 Agent | 可行性、成本、模型限制和替代方案 | 标记高风险镜头、建议试拍范围 | 自行增加预算、调用付费模型或发布 |
| 独立评审 Agent | 匿名评分和问题归因 | 按量表提出不通过意见 | 参与创作、修改被评作品 |
| 人类盲审组 | 真实观众和专业意见 | 对剧本与成片给出最终质量证据 | 访问作者身份、提前影响创作 |
| Codex/Hermes 监督者 | 调度、冲突处理、证据汇总 | 改派任务、要求返工、冻结开发 | 替用户接受条款、替用户公开发布 |

## 两条硬隔离

### 创作与评审隔离

编剧、导演、摄影/美术 Agent 的上下文不得包含其他编剧初稿和盲审身份。独立评审只接收匿名编号、版本和评审量表。评审完成前不得展示作者、模型或创作路径。

### 产品与作品隔离

锁定剧本和导演阐述是产品输入，不因 DirectorKit 当前能力不足而悄悄删改。适配发生变化时，必须记录“原剧情节拍、适配决定、产品限制、接受人和版本”。

## 阶段授权

| 阶段 | 进入条件 | 放行人 | 失败处理 |
| --- | --- | --- | --- |
| 简报 | 受众、时长、题材、版权边界明确 | Showrunner | 补齐简报 |
| 提案 | 3 名编剧各自独立完成 3 个提案 | Showrunner + 故事编辑 | 退回缺少冲突或结尾的提案 |
| 锁定剧本 | 桌读完成、结构评分达标 | Showrunner | 故事编辑返工，禁止进入 DirectorKit |
| DirectorKit | 每个关键节拍有镜头映射 | 导演 + AI 制片监督 | 标记适配偏差并返工 |
| 付费试拍 | 风险镜头、预算和调用次数明确 | Showrunner + 用户 | 未批准不得调用付费模型 |
| 成片盲测 | 资产来源、版本、隐私和版权检查完成 | Showrunner | 修复或停止，不公开 |
| 公开发布/提交 | 用户明确批准，条款和声明复核完成 | 用户本人 | 任何缺失都停止 |

## 预算与外部行动

- 子 Agent 不得自行创建付费资源、充值、购买模型额度、接受比赛条款或提交作品。
- 任何付费调用必须先给出模型、次数、上限、预期产物和失败策略；没有批准就只做静态或本地验证。
- 任何公网部署、公开视频、Devpost 提交、第三方凭据上传和版权敏感素材使用，都必须由用户单独批准。
- 失败默认停止并报告，不自动重试。连续三次同根因失败必须升级给 Showrunner。

## 交接格式

每次交接必须包含：`输入版本、输出路径、决策摘要、未解决问题、风险等级、下一位角色、验收条件`。仅有“已完成”或聊天截图不算交接证据。

## 监督模型

默认由 Hermes/Codex 负责跨角色调度和最终汇总；`5.6 luna` 适合提案展开、格式整理、量表打分初稿、连续性清单等边界清晰任务。任何涉及创作锁定、冲突仲裁、质量门禁、成本、版权、隐私和公开行动的结论，必须由 Showrunner 或人类复核。
