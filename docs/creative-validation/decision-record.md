# 创作验证季决策记录

日期：2026-08-26
决策人：项目所有者 + Hermes Orchestrator
状态：生效

## 决策

镜词停止常规功能扩张，进入六周创作验证季。现有产品作为受测系统，不先修改 DirectorKit Schema、公共 API 或 UI。

## 原因

当前产品已证明项目管理、镜头执行、证据、审批、交接和反馈链路，但故事层仍主要由单次模型调用同时完成诊断、改写、故事设定和分镜。继续增加工作台能力不能证明故事质量、导演化忠实度或观众价值。

## 开发准入

只有以下改动可以进入工程队列：

1. 严重缺陷、安全问题或数据丢失风险。
2. 完成实验不可缺少的最小测量能力。
3. 同类产品障碍在至少两部基准片中重复出现，并有失败归因证据。

付费生成、真实人物或敏感素材、外部招募、公开发布和平台提交仍需项目所有者单独批准。

## 恢复产品开发的门槛

完成三级片单和总验证报告后，由 Hermes 根据证据选择：建设专业剧本改编层、加强生成调度、回到故事与剪辑体系，或将通过验证的流程产品化。
