# 镜词创作验证季 · 基准片单

状态：已批准
周期：6 周
负责人：Showrunner Agent
适用范围：镜词项目创作验证，不属于 Agent Team OS 通用能力建设

## 验证目标

本片单用于回答三个问题：

1. 专业创作流程能否稳定产出有创意、完整且可拍的短片剧本。
2. 镜词能否忠实地把锁定剧本转换为 DirectorKit，而不遗漏、曲解或擅自增加关键剧情节拍。
3. DirectorKit 能否支持生成普通观众愿意看完、看懂并记住的成片。

## 执行编排

本片单由 Jingci Showrunner 负责调度和最终交接。编剧、故事编辑、导演、摄影美术、AI 制片监督和独立评审均以版本化文件交接；任何 Agent 不得把聊天记录当作唯一依据。

为降低执行成本，常规资料整理、格式检查、提案初稿和证据索引任务默认派发给 `5.6luna` 子 Agent。Showrunner 负责拆分任务、检查输入隔离、复核产物质量和处理冲突；涉及关卡放行、原创性风险、预算、权利、隐私、发布或产品结论的任务必须由 Showrunner 或项目所有者复核，不能因为模型更快而跳过独立审查。

同一模型承担不同角色时，必须使用独立上下文、角色专属输入和不同的否决标准。`5.6luna` 只影响执行路由，不降低质量门槛，也不能替代真人盲审或项目所有者审批。

验证季暂停常规功能扩张。首轮不修改 DirectorKit Schema、API 或 UI，只记录由真实作品暴露的问题。除安全、数据损坏问题外，同类障碍至少在两部作品中重复出现，才进入后续开发候选。

## 统一创作边界

- 原创 IP，不借用已有影视、动漫、游戏角色或世界观。
- 中文语境，面向普通大众，不依赖行业知识才能看懂。
- 移动端 `9:16`，画面承担主要叙事功能。
- 角色、地点和复杂度必须服从对应级别的验证目标。
- 不以对白解释剧情，不以片尾文字补救未讲清的故事。
- 每部作品均保留创作简报、提案、节拍表、锁定剧本、导演阐述、DirectorKit、镜头映射、试拍、盲审和归因记录。

## 已批准三级片单

| 编号 | 基准片 | 时长 | 约束 | 核心验证问题 |
| --- | --- | ---: | --- | --- |
| `film-01` | 日常视觉反转片 | 30 秒 | 1 名角色、1 个地点、无对白或极少对白 | 钩子、视觉叙事、镜头经济性、结尾回收 |
| `film-02` | 情感叙事片 | 60 秒 | 1 名主角、最多 2 个地点、有明确选择与代价 | 人物动机、情绪递进、表演、角色连续性 |
| `film-03` | 双角色悬疑或轻科幻片 | 90 秒 | 2 名角色、最多 3 个地点、三幕结构、伏笔与揭示 | 因果叙事、多角色调度、跨场景连续性、完整剪辑 |

三部影片采用一周错峰的滚动流水线：下一部可以开展不依赖前片结论的研究和提案，但不得越过自己的盲选、锁稿、导演化和试拍门禁。前片暴露的问题可加入后片观察项；若问题会改变后片简报或质量标准，Showrunner 必须暂停对应下游关卡，不能为了六周期限压缩评审或借机扩展产品功能。

## 对照设计

每部作品建立三组独立产物：

- **A 组**：把入选提案的一句话原始创意直接输入当前镜词。
- **B 组**：把经过桌读、故事编辑和批准的锁定剧本输入当前镜词。
- **C 组**：导演 Agent 根据同一锁定剧本人工制作镜头方案，作为参考标准。

评审材料仅使用随机编号，不暴露组别、作者或生成路径。创作者不能评审自己的产物，评审不得通过措辞、文件名或元数据推断来源。

## 放行门槛

- 剧本评分覆盖钩子、清晰度、因果、人物、原创性、结尾回收；平均分不低于 `4/5`，单项不低于 `3.5/5`。
- DirectorKit 对锁定剧本关键节拍的可追溯率为 `100%`，关键遗漏和无依据新增均为 `0`。
- 五名真人盲审中至少 `4/5` 能正确复述故事与结尾。
- 成片观看意愿平均分不低于 `4/5`。
- 严重角色、空间或道具连续性错误为 `0`。
- 每个缺陷必须归入：故事、导演化、生成、剪辑声音或产品工作流。

## 决策纪律

- 九个提案完成前不得选择题材方向。
- 提案作者之间不得交换初稿或借用彼此的核心机关。
- Showrunner 负责流程完整性和放行，不以个人偏好替代盲审证据。
- 最终胜选必须由匿名评分、可拍性复核和原创性风险共同决定。
- 当前文件批准的是验证片单与流程，不代表任何 `film-01` 提案已经入选。
