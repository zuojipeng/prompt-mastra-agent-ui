# 镜词创作验证季

## 目的

本目录定义镜词首个六周创作验证季。期间暂停常规功能开发，先验证：

1. 创作团队能否稳定产出完整、有创意且可拍的原创剧本。
2. 镜词能否把锁定剧本忠实转换为 DirectorKit。
3. DirectorKit 能否支持产出让普通观众看懂、看完并愿意记住的短片。

这不是“让 Agent 多写几版文案”的流程，而是一套有创作权、评审权和放行权分离的制作流程。

## 适用范围

- 中文语境、原创 IP、移动端 9:16、大众叙事短片。
- 三部基准片：30 秒日常反转、60 秒情感叙事、90 秒双角色悬疑或轻科幻。
- 产物归镜词项目；本轮不修改主机级 Agent Team OS 仓库。镜词项目内的 `docs/team-os/task-ledger.md` 仍作为验证证据账本维护。

## 工作原则

- 剧本先锁定，DirectorKit 后适配；不得用产品限制替代故事判断。
- 创作者不得担任自己作品的最终评审。
- 每个结论必须有版本化产物、评审记录或测试证据。
- Agent 可以提案和执行，Showrunner 负责阶段决策，人类负责最终创作、预算、版权和公开发布授权。
- 轻量、批量、格式化任务默认交给 `5.6 luna` 子 Agent；需要跨阶段判断、质量仲裁、预算或公开发布决策时，由 Showrunner 使用更强模型复核，不把模型名称写入作品或对外声明。

## 最小流程

`创作简报 -> 9 个独立提案 -> 盲选 -> 节拍表 -> 剧本 -> 桌读 -> 故事编辑 -> 锁定 -> 导演阐述 -> DirectorKit -> 试拍 -> 成片 -> 盲测 -> 归因复盘`

## 成功标准

- 剧本平均评分不低于 `4/5`，任何核心项不低于 `3.5/5`。
- 关键剧情节拍到 DirectorKit 的追踪率为 `100%`，关键遗漏和无依据新增为 `0`。
- 5 人真人盲测中至少 4 人正确理解故事和结尾。
- 观看意愿平均不低于 `4/5`，严重连续性错误为 `0`。
- 产品问题只有在至少两部作品中复现，才进入开发候选；安全、数据损坏和版权风险例外升级。

## 目录约定

每部片使用独立编号目录：`film-01`、`film-02`、`film-03`。至少保留：

`brief/ pitches/ beat-sheet/ screenplay/ bible/ treatment/ director-kit/ shot-map/ feasibility/ blind-review/ postmortem`

文件名必须带版本号或锁定状态；禁止用聊天记录作为唯一交接物。
