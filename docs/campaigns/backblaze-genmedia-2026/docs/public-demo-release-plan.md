# Public Judge Demo Release Plan

Status: READY FOR HUMAN PUBLICATION DECISION

Owners: Architecture Agent + Engineering Agent + DevOps Agent

Reviewers: Security Agent + Code Review Agent + Test Agent + Claims Review Agent

## Purpose

Provide judges a functioning Jingci workflow without exposing the private Cloudflare Access deployment, B2 credentials, provider credentials, or a public mutation endpoint. This is a deterministic product demonstration, not a live B2 or Genblaze transaction.

## Runtime Boundary

- Build with exact `NEXT_PUBLIC_DEMO_MODE=fixture`.
- `createDirectorKit` returns deterministic local data and performs no fetch.
- Provenance transport is forced to visibly labeled `Fixture`, even if a preview API URL is accidentally configured.
- Feedback, analytics, history, user sync, and project cloud sync return local empty/unavailable results without fetch.
- Project edits and receipts remain browser-local only.
- The public deployment contains static `out/` files only: no `functions/` directory, no Pages Function, no B2 binding, no Access token, and no provider secret.
- The UI states: `Public judge demo · deterministic local data · external API and cloud writes disabled`.

## Proposed Cloud Resource

- Platform: Cloudflare Pages.
- Separate project: `jingci-genmedia-judge-demo-2026`.
- Visibility: public, anonymous HTTPS.
- Source: one frozen commit from `spike/backblaze-provenance`.
- Deployment input: the verified static staging package generated by `npm run hackathon:public-demo:package`.
- Secrets: none.
- Paid calls: none.

Creating the project and making it public require explicit human approval. This plan does not grant that authority.

## Pre-Deploy Gates

1. Clean source commit and zero tracked-secret findings.
2. Node 22.21.1 TypeScript, ESLint, full Vitest, and production build pass.
3. Desktop and mobile Playwright complete the DirectorKit and Fixture provenance path.
4. Browser request log contains no optimization Worker or `/api/provenance` request even when both URLs are injected at build/dev time.
5. Static staging package contains no Function source, environment file, credential, signed URL, private evidence, or account identifier.
6. The generated Cloudflare Function route file `_routes.json` is excluded from the static staging package.

## Post-Deploy Smoke

1. Anonymous `GET /` returns HTTP 200.
2. The public-demo status is visible before interaction.
3. Desktop and mobile complete diagnosis, reconstruction, DirectorKit, and Fixture provenance.
4. Browser traffic contains no external API, B2, Runway, Genblaze service, or Pages Function request.
5. Source and manifest locations remain labeled Fixture, not B2.
6. No console-blocking error or private identifier appears.

## Rollback

- If any pre/post-deploy gate fails, delete or disable the separate Pages project and retain the existing owner-only preview unchanged.
- Do not weaken Access on `jingci-genmedia-preview-2026`.
- Do not upload B2 credentials or copy Pages Functions into the public project.

## Claims Boundary

The public app proves the Jingci workflow and UI using deterministic local data. The separately approved video/submission wording may describe the private Runway generation and separate Genblaze-to-B2 recovery verification only with its mandatory qualification. The public app must not imply that its Fixture action invokes Runway, Genblaze, or B2.
